# Mrfzccl - 明日方舟猜猜乐插件 v1.1.4

一个基于 AstrBot 的明日方舟干员猜谜游戏插件，通过遮挡干员立绘让玩家猜测干员名称，并记录答题统计信息。

## 🎮 游戏功能

### 基本游戏命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/fc` | 开始新游戏，获取遮挡后的干员立绘 | `/fc` |
| `/fcc [干员名]` | 猜测干员名称 | `/fcc 能天使` |
| `/fct` | 获取提示（可多次使用） | `/fct` |
| `/fce` | 强制结束当前游戏，显示答案 | `/fce` |

### 新增功能（v1.1.0）
- **排行榜系统**：多种维度的排行榜展示
- **个人档案**：查看详细的答题统计数据
- **图片可视化**：排行榜图片展示(作者的美术水平有限,做不了好看的图喵)
- **数据持久化**：SQLite数据库存储用户数据

## 📊 统计系统命令

| 命令               | 说明 | 示例 |
|------------------|------|------|
| `/ccl 排行榜`       | 正确量排行榜（前10名） | `/ccl 排行榜` |
| `/ccl 错误排行榜`     | 错误量排行榜（前10名） | `/ccl 错误排行榜` |
| `/ccl 提示排行榜`     | 提示使用排行榜（前10名） | `/ccl 提示排行榜` |
| `/ccl 名片 [用户ID]` | 查询用户答题档案 | `/ccl 名片` 或 `/ccl 名片 123456` |

## 🎯 游戏规则

1. **开始游戏**：使用 `/fc` 开始新游戏，会收到一张被遮挡的干员立绘
2. **猜测干员**：使用 `/fcc 干员名` 来猜测干员身份
3. **智能匹配**：支持模糊匹配，相似度超过60%就算正确
4. **提示系统**：可使用 `/fct` 获取提示，包括：
   - 第1次：职业分支
   - 第2次：阵营
   - 第3次：性别
   - 第4次：干员名前2个字
   - 第5次：干员名前3个字
   - ...以此类推
5. **游戏结束**：可使用 `/fce` 随时结束游戏查看答案
6. **会话限制**：每个用户/群组同一时间只能进行一局游戏

## 💡 使用技巧

- **输入格式**：直接输入干员名称，如"能天使"、"陈"，不需要加任何符号
- **相似度匹配**：允许少量错别字，比如"能天师"也能识别
- **快速结束**：猜不出来时使用 `/fce` 结束游戏查看答案
- **统计数据**：通过排行榜了解自己的游戏水平

## 📈 排行榜特色

### 🏆 正确量排行榜 (`/ccl 排行榜`)
- 显示答题正确次数最多的前10名用户
- 包含准确率、总答题数等详细信息
- 支持图片和文本两种显示模式

### 💥 错误量排行榜 (`/ccl 错误排行榜`)
- 显示答题错误次数最多的前10名用户
- 计算错误率，帮助了解常见错误
- 有趣的炸弹图标标识前三名

### 💡 提示使用排行榜 (`/ccl 提示排行榜`)
- 显示使用提示次数最多的前10名用户
- 计算平均每道题提示使用频率
- 标识依赖提示的玩家

### 👤 个人档案 (`/ccl 名片`)
- 查看个人详细答题统计数据
- 显示在各项排行榜中的排名
- 包含注册时间和最后活动时间

## ❓ 常见问题

### Q：提示"插件未加载成功"怎么办？
A：请管理员检查配置文件和数据文件路径是否正确

### Q：猜错了怎么办？
A：可以继续猜测，直到猜对或使用 `/fce` 结束

### Q：可以同时玩多局吗？
A：不能，每个用户/群组同一时间只能进行一局游戏

### Q：排行榜图片显示不出来？
A：插件会自动回退到文本模式显示，不影响功能使用

## ⚙️ 技术特性

### 性能优化
- **全异步架构**：高效处理图片下载和数据库操作
- **连接池管理**：限制HTTP连接数，防止资源耗尽
- **自动清理**：定期清理临时图片文件

### 错误处理
- **完善的异常处理**：所有操作都有错误捕获和日志记录
- **优雅降级**：图片生成失败时自动使用文本模式
- **资源管理**：插件关闭时自动清理所有资源

### 数据安全
- **输入过滤**：自动清理用户输入，防止注入攻击
- **权限控制**：禁止访问内网URL
- **文件验证**：验证图片格式和大小
