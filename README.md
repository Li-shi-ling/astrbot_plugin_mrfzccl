# 明日方舟猜猜乐插件使用说明

## 🎮 游戏命令

### 1. 开始游戏
**命令：** `/fc`
**说明：** 开始新游戏，会发送一张被遮挡的干员立绘
**示例：** `/fc`

### 2. 猜干员
**命令：** `/fcc [干员名称]`
**说明：** 猜测图片中的干员是谁
**示例：** `/fcc 能天使`
**注意：** 支持部分匹配，相似度超过60%就算正确

### 3. 结束游戏
**命令：** `/fce`
**说明：** 强制结束当前游戏，显示正确答案
**示例：** `/fce`

### 4. 查看帮助
**命令：** `/fch`
**说明：** 查看插件使用说明
**示例：** `/fch`

### 5. 查看帮助
**命令：** `/fct`
**说明：** 获取提示
**示例：** `/fct`

## 🎯 游戏规则

1. 使用 `/fc` 开始游戏后，会收到一张被遮挡的干员立绘
2. 使用 `/fcc 干员名` 来猜测干员身份
3. 支持模糊匹配，打错部分字也可能算对
4. 可以使用 `/fce` 随时结束游戏查看答案
5. 每个用户/群组同一时间只能进行一局游戏

## 💡 使用技巧

- **输入格式：** 直接输入干员名称，如“能天使”、“陈”
- **相似度：** 允许少量错别字，比如“能天师”也能识别
- **游戏限制：** 不能重复开始，需要先结束当前游戏
- **图片大小：** 图片会自动调整到合适尺寸

## ❓ 常见问题

**Q：提示“数据加载失败”怎么办？**
A：请联系管理员检查配置文件和数据文件

**Q：猜错了怎么办？**
A：可以继续猜测，直到猜对或使用 `/fce` 结束

**Q：可以同时玩多局吗？**
A：不能，每个用户/群组同一时间只能进行一局

## 📝 注意事项

1. 游戏图片来自预先配置的数据源
2. 输入干员名时不需要加任何符号
3. 支持中英文和数字，会自动过滤特殊字符
4. 长时间无操作不会自动结束，请手动使用 `/fce`
